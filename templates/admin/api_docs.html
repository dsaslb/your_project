데이터베이스 스키마

핵심 테이블

IndustryAdmin

업종별 관리자 정보

• id (Primary Key)
• full_name (VARCHAR)
• contact_email (VARCHAR)
• industry_name (VARCHAR)
• status (ENUM)
• created_at (TIMESTAMP)
Module

플러그인/모듈 정보

• id (Primary Key)
• name (VARCHAR)
• version (VARCHAR)
• description (TEXT)
• is_active (BOOLEAN)
• created_at (TIMESTAMP)
SystemLog

시스템 로그

• id (Primary Key)
• level (ENUM)
• message (TEXT)
• source (VARCHAR)
• timestamp (TIMESTAMP)
Notification

알림 정보

• id (Primary Key)
• title (VARCHAR)
• content (TEXT)
• is_urgent (BOOLEAN)
• created_at (TIMESTAMP)

관계도

IndustryAdmin → Module (관리자가 플러그인 관리)
SystemLog ← 모든 테이블 (시스템 활동 로깅)
Notification → User (알림 전송)

운영 정책

보안 정책

접근 제어
  • • 관리자 계정은 2단계 인증 필수
  • • IP 화이트리스트 기반 접근 제한
  • • 세션 타임아웃: 60분
  • • 로그인 시도 제한: 5회
데이터 보호
  • • 민감한 데이터 암호화 저장
  • • 데이터 접근 감사 로그 필수
  • • 백업 데이터 암호화
  • • 정기적인 보안 점검

플러그인 정책

샌드박스 실행
  • • 모든 플러그인은 샌드박스 환경에서 실행
  • • 메모리 사용량 제한: 512MB
  • • 파일 시스템 접근 제한
  • • 네트워크 접근 제한

모니터링 정책

시스템 모니터링
  • • CPU 사용률 80% 초과 시 경고
  • • 메모리 사용률 85% 초과 시 경고
  • • 디스크 사용률 90% 초과 시 경고
  • • 응답 시간 5초 초과 시 경고

배포 가이드

환경 요구사항

서버 요구사항
  • • CPU: 4코어 이상
  • • RAM: 8GB 이상
  • • Storage: 100GB 이상
  • • OS: Ubuntu 20.04+
소프트웨어 요구사항
  • • Python 3.8+
  • • PostgreSQL 12+
  • • Redis 6+
  • • Nginx

• 로그 수집 설정
