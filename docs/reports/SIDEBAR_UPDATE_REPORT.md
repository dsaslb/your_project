**작성일**: 2025년 7월 29일  
**업데이트 담당**: AI 어시스턴트  
**파일**: `frontend/src/components/Sidebar.tsx`

## 🎯 업데이트 개요

사이드바에 **AI 시스템 모니터링** 메뉴를 추가하여 시스템 상태와 고급 분석 페이지에 쉽게 접근할 수 있도록 개선했습니다.

## 📋 추가된 메뉴 구조

### 1. AI 시스템 모니터링 메뉴
```
🧠 AI 시스템 모니터링
├── 📊 시스템 상태 (/system-health)
└── 📈 고급 분석 (/advanced-analytics)
```

### 2. 권한별 접근 설정
- **최고 관리자 (super_admin)**: ✅ 접근 가능
- **브랜드 관리자 (brand_manager)**: ✅ 접근 가능  
- **매장 관리자 (store_manager)**: ✅ 접근 가능
- **직원 (employee)**: ❌ 접근 불가

## 🎨 UI/UX 개선사항

### 1. 직관적인 아이콘
- **🧠 Brain**: AI 시스템 모니터링을 나타내는 뇌 아이콘
- **📊 Monitor**: 시스템 상태를 나타내는 모니터 아이콘
- **📈 TrendingUp**: 고급 분석을 나타내는 트렌드 아이콘

### 2. 권한 기반 접근
- 관리자 권한이 있는 사용자만 접근 가능
- 역할별로 적절한 메뉴 표시
- 보안 강화

### 3. 일관된 디자인
- 기존 사이드바 디자인과 일치
- 호버 효과 및 활성 상태 표시
- 반응형 디자인 유지

## 🔐 보안 고려사항

### 1. 권한 제어
- `super_admin`, `brand_manager`, `store_manager` 권한만 접근
- 일반 직원은 접근 불가
- 역할 기반 메뉴 표시

### 2. 라우팅 보호
- 프론트엔드에서 권한 체크
- 백엔드 API에서도 추가 인증 필요
- `@login_required` 데코레이터 적용

## 📱 사용법

### 1. 사이드바 접근
1. 웹 브라우저에서 `http://localhost:3000` 접속
2. 로그인 후 사이드바 확인
3. **AI 시스템 모니터링** 메뉴 클릭

### 2. 시스템 상태 확인
1. **AI 시스템 모니터링** → **시스템 상태** 클릭
2. 실시간 시스템 상태 확인
3. 필요시 **최적화 실행** 버튼 클릭

### 3. 고급 분석 사용
1. **AI 시스템 모니터링** → **고급 분석** 클릭
2. AI 예측 결과 확인
3. **AI 모델 훈련** 버튼으로 모델 업데이트
