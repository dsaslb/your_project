# 🏗️ 레스토랑 백엔드-프론트엔드 계층 구조

## 📋 구조 개요

레스토랑 관리 시스템은 **백엔드에서 업종별 관리자 페이지**를 제공하고, **프론트엔드에서 브랜드 > 매장 > 직원 계층**을 구현하는 구조로 설계되었습니다.

```
🍽️ 백엔드: 업종별 관리자 페이지
    ↓ (API 제공)
🏪 프론트엔드: 브랜드별 관리자 보드
    ↓ (하위 계층)
🏢 프론트엔드: 매장별 관리자 보드  
    ↓ (하위 계층)
👤 프론트엔드: 직원별 보드
```

## 🎯 아키텍처 설계

### 백엔드 (Backend)
- **역할**: 업종 전체 관리자 페이지
- **접근 권한**: 관리자, 슈퍼 관리자
- **기능**: 업종 전체 통계, 브랜드/매장/직원 요약 정보
- **API 제공**: 프론트엔드에 데이터 제공

### 프론트엔드 (Frontend)
- **역할**: 계층적 사용자 인터페이스
- **구조**: 브랜드 > 매장 > 직원 3단계 계층
- **사용자**: 브랜드 관리자, 매장 관리자, 직원
- **기능**: 각 계층별 상세 관리 및 모니터링

## 🚀 구현된 기능

### 1️⃣ 백엔드 업종 관리자 페이지

#### URL: `/admin/restaurant/industry`
- **업종 전체 통계**: 오늘 매출, 주문 수, 브랜드 수, 직원 수
- **브랜드별 요약**: 각 브랜드의 현황 및 성과
- **매장별 요약**: 모든 매장의 운영 현황
- **직원별 요약**: 전체 직원의 성과 현황
- **최근 활동**: 실시간 시스템 활동 내역

#### API 엔드포인트
```python
# 업종 통계 API
GET /api/admin/restaurant/industry/stats

# 브랜드 목록 API  
GET /api/admin/restaurant/industry/brands

# 매장 목록 API
GET /api/admin/restaurant/industry/branches

# 직원 목록 API
GET /api/admin/restaurant/industry/staff
```

### 2️⃣ 프론트엔드 계층적 구조

#### 브랜드 레벨
- **브랜드별 현황**: 매출, 매장 수, 직원 수
- **소속 매장 목록**: 브랜드에 속한 모든 매장
- **브랜드 트렌드**: 매출 및 성과 분석
- **매장별 성과 비교**: 소속 매장 간 비교

#### 매장 레벨
- **매장별 실시간 현황**: 오늘 매출, 주문, 직원 수
- **실시간 주문 현황**: 최근 30분 내 주문 내역
- **재고 부족 알림**: 재고가 부족한 아이템
- **직원 현황**: 해당 매장 직원들의 상태
- **빠른 액션**: 새 주문, 재고 발주, 직원 관리

#### 직원 레벨
- **개인 성과 통계**: 처리 주문 수, 매출 기여도
- **스케줄 관리**: 오늘/내일 스케줄 확인
- **성과 분석**: 최근 30일 성과 데이터
- **개인 목표 및 성취**: 목표 대비 달성률

## 🔗 데이터 흐름

### 1️⃣ 백엔드 → 프론트엔드
```
백엔드 API → 프론트엔드 컴포넌트 → 사용자 인터페이스
```

### 2️⃣ 계층별 데이터 필터링
```javascript
// 브랜드별 매장 필터링
const getBranchesByBrand = (brandId) => {
  return branches.filter(branch => 
    branch.brand_name === brands.find(b => b.id === brandId)?.name
  );
};

// 매장별 직원 필터링
const getStaffByBranch = (branchId) => {
  return staff.filter(s => 
    s.branch_name === branches.find(b => b.id === branchId)?.name
  );
};
```
