# 운영 체크리스트 (Operations Checklist)

---

## 일일 점검
- [ ] 시스템 리소스(CPU/메모리/디스크) 모니터링
- [ ] 서비스/컨테이너 상태 확인 (`/api/admin/ops/status`)
- [ ] 장애/복구/보안 알림 확인 (`/api/admin/ops/alerts`)
- [ ] 주요 로그/에러 로그 점검 (`/api/admin/ops/logs`)
- [ ] 백업 상태/최근 백업 확인
- [ ] 실시간 대시보드/통계 확인
- [ ] 주요 알림/공지/피드백 확인

---

## 주간 점검
- [ ] 성능 리포트/통계 대시보드 점검
- [ ] 보안 점검/취약점 스캔 (`scripts/security_scan.sh`)
- [ ] 백업 복구 테스트
- [ ] 시스템/패키지 업데이트
- [ ] 비용/리소스 사용량 점검
- [ ] 플러그인/모듈 업데이트

---

## 월간 점검
- [ ] 전체 시스템 감사/운영 리포트
- [ ] 성능 최적화/불필요 리소스 정리
- [ ] 보안 정책/권한 검토
- [ ] 재해 복구 시나리오 점검
- [ ] 비용/예산 분석

---

## 장애/이벤트 발생 시
- [ ] 장애 자동 복구/롤백 스크립트 실행 (`scripts/auto_recover.sh`)
- [ ] 관리자/운영자 알림(이메일/슬랙 등) 확인
- [ ] 장애 원인 분석 및 재발 방지 조치
- [ ] 장애/복구/알림 내역 기록 및 리포트

---

## 배포/업데이트 전후
- [ ] 배포 전 전체 백업
- [ ] 신규 기능/변경점 테스트
- [ ] 배포 후 서비스/컨테이너 상태 확인
- [ ] 주요 기능/알림/통계 정상 동작 확인
- [ ] 롤백/복구 시나리오 준비
