# 🍽️ 레스토랑 특화 관리자 대시보드

## 개요

레스토랑 특화 관리자 대시보드는 레스토랑 업종에 특화된 실시간 모니터링, 분석, 인사이트를 제공하는 고도화된 대시보드입니다. 기존 대시보드보다 더 상세하고 레스토랑 업종에 최적화된 기능들을 포함합니다.

## 주요 기능

### 1. 실시간 모니터링
- **실시간 주문 현황**: 최근 주문들의 상태와 진행 상황을 실시간으로 표시
- **재고 알림**: 부족한 재고 아이템에 대한 즉시 알림
- **직원 현황**: 현재 근무 중인 직원들의 상태와 위치
- **예약 현황**: 오늘의 예약 상황과 고객 정보

### 2. 매출 분석
- **일별/주별/월별 매출 트렌드**: 시계열 데이터를 통한 매출 변화 분석
- **시간대별 주문 분석**: 피크 시간대와 저조 시간대 식별
- **요일별 매출 패턴**: 요일별 매출 특성 분석
- **성장률 계산**: 이전 기간 대비 매출 증감률

### 3. 메뉴 성과 분석
- **인기 메뉴 순위**: 판매량과 매출 기준 인기 메뉴 분석
- **카테고리별 성과**: 메뉴 카테고리별 매출 분포
- **수익성 분석**: 메뉴별 마진과 수익성 평가
- **메뉴 개선 제안**: 저수익 메뉴에 대한 개선 방안 제시

### 4. 고객 행동 분석
- **RFM 분석**: Recency, Frequency, Monetary 기반 고객 세분화
- **고객 세그먼트**: VIP, 정기, 일회성, 이탈 위험 고객 분류
- **방문 빈도 분석**: 고객별 방문 패턴 분석
- **평균 주문 금액 분포**: 고객별 주문 금액 특성

### 5. 운영 인사이트
- **피크 시간대 분석**: 가장 바쁜 시간대와 최적 인력 배치 제안
- **재고 최적화**: 부족/과잉 재고 식별 및 발주 권장
- **직원 효율성**: 직원별 성과 분석 및 개선 방안
- **수익성 개선 기회**: 수익성 향상을 위한 구체적 제안

### 2. 매출 분석 API
```
GET /api/restaurant/sales-analysis?period=week&branch_id=1
```
**쿼리 파라미터:**
- `period`: week, month, quarter
- `branch_id`: 매장 ID (선택사항)

### 3. 메뉴 성과 분석 API
```
GET /api/restaurant/menu-performance?period=month&branch_id=1
```

### 4. 고객 행동 분석 API
```
GET /api/restaurant/customer-behavior?period=month&branch_id=1
```

### 5. 운영 인사이트 API
```
GET /api/restaurant/operational-insights?branch_id=1
```

## 대시보드 구성 요소

### 1. 헤더 섹션
- 현재 시간 표시
- 영업 상태 표시
- 사용자 정보 및 로그아웃

### 2. 실시간 알림 섹션
- 긴급 알림 메시지
- 재고 부족, 주문 지연 등

### 3. 주요 지표 카드
- 오늘 매출 (증감률 포함)
- 오늘 주문 수 (증감률 포함)
- 평균 주문 금액
- 고객 만족도

### 4. 메인 콘텐츠 그리드
- **왼쪽 컬럼**: 실시간 모니터링
  - 실시간 주문 현황
  - 매출 트렌드 차트
  - 인기 메뉴 분석
- **오른쪽 컬럼**: 빠른 액션 및 알림
  - 빠른 액션 버튼
  - 재고 알림
  - 직원 현황
  - 예약 현황

### 5. 하단 분석 섹션
- 고객 분석 차트
- 시간대별 주문 분석 차트

## 차트 및 시각화

### 1. 매출 트렌드 차트
- Chart.js를 사용한 라인 차트
- 최근 7일 매출 변화
- 호버 시 상세 정보 표시

### 2. 고객 분석 차트
- 도넛 차트로 고객 유형 분포
- 신규/재방문/VIP 고객 비율

### 3. 시간대별 주문 분석
- 바 차트로 시간대별 주문 수
- 11시부터 23시까지

## 실시간 업데이트

### 자동 새로고침
- 10초마다 실시간 데이터 자동 업데이트
- WebSocket 연결로 즉시 알림 수신

### 업데이트되는 데이터
- 실시간 주문 현황
- 재고 상태
- 직원 현황
- 예약 정보

## 사용 팁

### 1. 효율적인 모니터링
- 피크 시간대에는 실시간 주문 현황에 집중
- 재고 알림을 주기적으로 확인
- 직원 현황으로 인력 배치 최적화

### 2. 데이터 분석 활용
- 매출 트렌드를 통해 마케팅 전략 수립
- 인기 메뉴 분석으로 메뉴 구성 개선
- 고객 행동 분석으로 고객 서비스 향상

### 3. 운영 최적화
- 피크 시간대 분석으로 인력 배치 최적화
- 재고 최적화 인사이트로 발주 시점 조정
- 수익성 개선 기회를 통한 메뉴 가격 정책 조정

## 문제 해결

### 1. 데이터가 표시되지 않는 경우
- 브라우저 새로고침
- 로그인 상태 확인
- 네트워크 연결 상태 확인

### 2. 실시간 업데이트가 안 되는 경우
- 브라우저 개발자 도구에서 네트워크 탭 확인
- JavaScript 콘솔에서 오류 메시지 확인
- 서버 연결 상태 확인

### 3. 차트가 표시되지 않는 경우
- Chart.js 라이브러리 로딩 확인
- 브라우저 캐시 삭제
- 다른 브라우저에서 테스트
