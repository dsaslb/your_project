## 대시보드 개요

### 메인 대시보드

메인 대시보드는 전체 시스템의 핵심 정보를 한눈에 볼 수 있는 중앙 허브입니다.

#### 대시보드 구성 요소

1. **시스템 상태 카드**
   ```
   ┌─────────────┬─────────────┬─────────────┬─────────────┐
   │   CPU 사용률│  메모리 사용률│  네트워크   │   디스크    │
   │    65%      │    45%      │   1.2GB/s  │    80%      │
   │    🟢 정상   │    🟢 정상   │   🟢 정상   │   🟡 주의   │
   └─────────────┴─────────────┴─────────────┴─────────────┘
   ```

2. **서비스 현황**
   - API Gateway: ✅ 정상
   - AI/ML Platform: ✅ 정상
   - Data Analysis: ✅ 정상
   - Blockchain: ✅ 정상
   - IoT Platform: ✅ 정상
   - Security Monitor: ✅ 정상

3. **실시간 메트릭**
   - API 요청 수: 1,234/분
   - 처리 중인 작업: 45개
   - 오류율: 0.1%
   - 응답 시간: 85ms

### 대시보드 사용법

#### 1. 위젯 사용자 정의

**위젯 추가**
1. 대시보드 우상단 "편집" 버튼 클릭
2. "위젯 추가" 선택
3. 원하는 위젯 유형 선택:
   - 차트 위젯
   - 테이블 위젯
   - 메트릭 위젯
   - 상태 위젯
4. 위젯 설정 구성 후 "저장"

**위젯 이동 및 크기 조정**
1. 편집 모드에서 위젯 클릭 및 드래그
2. 위젯 모서리를 드래그하여 크기 조정
3. "저장" 버튼으로 변경사항 저장

#### 2. 필터 및 시간 범위 설정

**시간 범위 선택**
```
┌─────────────────────────────────────┐
│ 📅 시간 범위: [최근 1시간 ▼]         │
│                                     │
│ • 최근 5분   • 최근 1시간             │
│ • 최근 1일   • 최근 1주               │
│ • 최근 1개월 • 사용자 정의            │
└─────────────────────────────────────┘
```

**데이터 필터**
1. 대시보드 상단 필터 영역 사용
2. 서비스별, 심각도별, 상태별 필터링 가능
3. 다중 필터 조합 지원

#### 3. 알림 설정

**대시보드 알림 구성**
1. 설정 → 알림 설정 메뉴 이동
2. 알림 유형 선택:
   - 이메일 알림
   - 브라우저 알림
   - 모바일 푸시 알림
3. 알림 조건 설정:
   - CPU 사용률 > 80%
   - 메모리 사용률 > 90%
   - 서비스 다운
   - 보안 위협 탐지

## 시스템 통합 기능

### 서비스 관리

시스템 통합 페이지에서는 모든 마이크로서비스를 중앙에서 관리할 수 있습니다.

#### 1. 서비스 현황 확인

**서비스 목록 보기**
```
┌──────────────────────────────────────────────────────┐
│ 서비스명        │ 상태  │ CPU  │ 메모리 │ 응답시간     │
├──────────────────────────────────────────────────────┤
│ API Gateway     │ 🟢   │ 45%  │ 512MB  │ 25ms        │
│ AI/ML Platform  │ 🟢   │ 78%  │ 2.1GB  │ 340ms       │
│ Data Analysis   │ 🟢   │ 32%  │ 1.5GB  │ 120ms       │
│ Blockchain      │ 🟡   │ 15%  │ 800MB  │ 450ms       │
│ IoT Platform    │ 🟢   │ 23%  │ 600MB  │ 85ms        │
│ Security Monitor│ 🟢   │ 12%  │ 400MB  │ 15ms        │
└──────────────────────────────────────────────────────┘
```

**서비스 상세 정보**
1. 서비스명 클릭 → 상세 페이지 이동
2. 확인 가능한 정보:
   - 실시간 로그
   - 성능 메트릭
   - 환경 설정
   - 헬스 체크 결과

#### 2. 서비스 제어

**서비스 시작/중지**
1. 서비스 목록에서 해당 서비스 선택
2. 상태 열의 "⚙️" 버튼 클릭
3. 작업 선택:
   - 🔄 재시작
   - ⏹️ 중지
   - ▶️ 시작
   - 📊 상세 보기

**배포 관리**
1. 서비스 상세 페이지 → "배포" 탭
2. 새 버전 배포:
   ```
   ┌─────────────────────────────────────┐
   │ 새 버전 배포                        │
   ├─────────────────────────────────────┤
   │ 현재 버전: v1.2.3                   │
   │ 새 버전: [v1.2.4        ] [확인]   │
   │                                     │
   │ 배포 전략:                          │
   │ ◉ 롤링 업데이트                     │
   │ ○ 블루-그린 배포                    │
   │ ○ 카나리 배포                       │
   │                                     │
   │ [미리보기] [배포 시작]              │
   └─────────────────────────────────────┘
   ```

#### 3. API 라우팅 관리

**라우팅 규칙 설정**
1. 시스템 통합 → API 게이트웨이 → 라우팅 설정
2. 새 라우트 추가:
   ```
   경로 패턴: /api/v2/users/*
   대상 서비스: User Management Service
   로드 밸런싱: Round Robin
   타임아웃: 30초
   재시도: 3회
   ```

**요청 추적**
1. API 게이트웨이 → 요청 추적 탭
2. 실시간 API 호출 모니터링
3. 필터링 옵션:
   - 시간 범위
   - HTTP 상태 코드
   - 응답 시간
   - 클라이언트 IP

## AI/ML 플랫폼

### 머신러닝 모델 관리

AI/ML 플랫폼에서는 머신러닝 모델의 전체 생명주기를 관리할 수 있습니다.

#### 1. 모델 목록 및 상태

**모델 대시보드**
```
┌──────────────────────────────────────────────────────┐
│ 모델명           │ 버전  │ 상태   │ 정확도 │ 마지막 업데이트│
├──────────────────────────────────────────────────────┤
│ 사용자 추천 모델  │ v2.1  │ 활성   │ 94.2%  │ 2시간 전      │
│ 이상 탐지 모델   │ v1.5  │ 활성   │ 87.8%  │ 1일 전        │
│ 텍스트 분류 모델  │ v3.0  │ 학습중 │ -      │ 진행 중       │
│ 이미지 인식 모델  │ v1.2  │ 비활성 │ 91.5%  │ 1주 전        │
└──────────────────────────────────────────────────────┘
```

#### 2. 새 모델 훈련

**모델 훈련 시작**
1. AI/ML → 모델 관리 → "새 모델 훈련" 버튼
2. 모델 설정:
   ```
   ┌─────────────────────────────────────┐
   │ 새 모델 훈련                        │
   ├─────────────────────────────────────┤
   │ 모델 이름: [고객 이탈 예측         ]│
   │ 알고리즘: [Random Forest    ▼]    │
   │ 데이터셋: [customer_data.csv ▼]   │
   │                                     │
   │ 하이퍼파라미터:                     │
   │ • 트리 개수: [100]                  │
   │ • 최대 깊이: [10]                   │
   │ • 최소 샘플: [5]                    │
   │                                     │
   │ 검증 방법:                          │
   │ ◉ K-Fold (k=5)                     │
   │ ○ Train/Test Split (80/20)         │
   │                                     │
   │ [훈련 시작] [저장 후 나중에]         │
   └─────────────────────────────────────┘
   ```

**훈련 진행 상황 모니터링**
1. 모델 목록에서 훈련 중인 모델 클릭
2. 실시간 진행 상황 확인:
   - 진행률 (%)
   - 현재 에포크/반복
   - 손실 함수 값
   - 검증 정확도
   - 예상 완료 시간

#### 3. 모델 배포 및 추론

**모델 배포**
1. 훈련 완료된 모델 선택
2. "배포" 버튼 클릭
3. 배포 설정:
   ```
   배포 환경: [프로덕션 ▼]
   인스턴스 수: [3]
   메모리 할당: [2GB]
   CPU 할당: [1 코어]
   오토스케일링: [활성화 ☑]
   ```

**실시간 추론 테스트**
1. 배포된 모델 → "추론 테스트" 탭
2. 테스트 데이터 입력:
   ```
   ┌─────────────────────────────────────┐
   │ 실시간 추론 테스트                  │
   ├─────────────────────────────────────┤
   │ 입력 형식: JSON                     │
   │ ┌─────────────────────────────────┐ │
   │ │ {                               │ │
   │ │   "age": 25,                    │ │
   │ │   "income": 50000,              │ │
   │ │   "usage_hours": 120            │ │
   │ │ }                               │ │
   │ └─────────────────────────────────┘ │
   │                                     │
   │ [예측 실행]                         │
   │                                     │
   │ 결과:                               │
   │ 이탈 확률: 23.4%                    │
   │ 신뢰도: 87.2%                       │
   │ 응답 시간: 15ms                     │
   └─────────────────────────────────────┘
   ```

#### 4. 모델 성능 모니터링

**성능 메트릭 대시보드**
1. 모델 상세 페이지 → "성능 모니터링" 탭
2. 주요 메트릭:
   - 요청 수/시간
   - 평균 응답 시간
   - 예측 정확도 (실시간 검증)
   - 에러율
   - 리소스 사용량

**데이터 드리프트 탐지**
1. "데이터 품질" 탭에서 드리프트 모니터링
2. 알림 설정:
   - 데이터 분포 변화 > 10%
   - 예측 정확도 < 85%
   - 입력 데이터 이상치 탐지

## 데이터 분석

### 비즈니스 인텔리전스 도구

데이터 분석 모듈은 강력한 BI 도구를 제공하여 데이터를 통한 인사이트 도출을 지원합니다.

#### 1. 대시보드 생성

**새 대시보드 만들기**
1. 데이터 분석 → "새 대시보드" 버튼
2. 대시보드 설정:
   ```
   ┌─────────────────────────────────────┐
   │ 새 대시보드 생성                    │
   ├─────────────────────────────────────┤
   │ 이름: [월간 매출 분석              ]│
   │ 설명: [월별 매출 동향 및 분석       ]│
   │ 태그: [매출, 월간, KPI            ]│
   │ 공유 설정:                          │
   │ ◉ 팀 전체 공유                      │
   │ ○ 특정 사용자만                     │
   │ ○ 비공개                            │
   │                                     │
   │ 템플릿:                             │
   │ ○ 빈 대시보드                       │
   │ ◉ 매출 분석 템플릿                  │
   │ ○ 사용자 행동 분석 템플릿            │
   │                                     │
   │ [생성] [취소]                       │
   └─────────────────────────────────────┘
   ```

#### 2. 차트 및 시각화

**차트 추가**
1. 대시보드 편집 모드 → "차트 추가"
2. 차트 유형 선택:
   - 📊 막대 차트
   - 📈 선 차트
   - 🥧 원형 차트
   - 📊 영역 차트
   - 🗺️ 히트맵
   - 📊 산점도

**데이터 소스 연결**
1. 차트 설정 → "데이터 소스" 탭
2. 연결 가능한 소스:
   - PostgreSQL 데이터베이스
   - CSV 파일 업로드
   - REST API 엔드포인트
   - 실시간 스트림 데이터

**차트 구성 예시 - 매출 트렌드**
```
┌─────────────────────────────────────┐
│ 차트 설정 - 월간 매출 트렌드         │
├─────────────────────────────────────┤
│ 데이터 소스: sales_data             │
│ X축: month (날짜)                   │
│ Y축: revenue (숫자)                 │
│ 그룹화: product_category            │
│                                     │
│ 필터:                               │
│ • 날짜 범위: 최근 12개월             │
│ • 제품 상태: 활성                   │
│                                     │
│ 스타일:                             │
│ • 색상: 카테고리별 자동 할당         │
│ • 선 두께: 2px                      │
│ • 마커 표시: 활성화                 │
│                                     │
│ [미리보기] [적용]                   │
└─────────────────────────────────────┘
```

#### 3. SQL 쿼리 에디터

**사용자 정의 쿼리 작성**
1. 데이터 분석 → "쿼리 에디터"
2. SQL 쿼리 작성 및 실행:
   ```sql
   -- 예시: 월별 신규 고객 및 매출 분석
   SELECT 
       DATE_TRUNC('month', created_at) as month,
       COUNT(DISTINCT customer_id) as new_customers,
       SUM(order_amount) as revenue,
       AVG(order_amount) as avg_order_value
   FROM orders 
   WHERE created_at >= '2024-01-01'
   GROUP BY DATE_TRUNC('month', created_at)
   ORDER BY month;
   ```

**쿼리 결과 시각화**
1. 쿼리 실행 후 "시각화" 탭 클릭

## 문제 해결

### 일반적인 문제 및 해결책

#### 1. 로그인 문제

**문제: 로그인할 수 없음**

**해결 방법:**
1. 사용자명/비밀번호 재확인
2. 계정 잠금 상태 확인
3. 2단계 인증 문제:
   - 시간 동기화 확인
   - 백업 코드 사용
4. 관리자에게 계정 상태 문의

**문제: 세션이 자주 만료됨**

**해결 방법:**
1. 브라우저 쿠키 설정 확인
2. 보안 설정에서 세션 시간 연장
3. "로그인 상태 유지" 옵션 활성화

#### 2. 성능 문제

**문제: 페이지 로딩이 느림**

**진단 및 해결:**
1. 브라우저 개발자 도구로 네트워크 탭 확인
2. 캐시 지우기:
   - Chrome: Ctrl+Shift+Del
   - Firefox: Ctrl+Shift+Del
3. 다른 브라우저에서 테스트
4. 네트워크 연결 상태 확인

**문제: 대시보드 데이터가 업데이트되지 않음**

**해결 방법:**
1. 페이지 새로고침 (F5)
2. 하드 새로고침 (Ctrl+F5)
3. 자동 새로고침 설정 확인
4. 데이터 소스 연결 상태 확인

#### 3. 기능별 문제

**AI/ML 모델 훈련 실패**

**확인 사항:**
1. 데이터셋 형식 및 크기
2. 사용 가능한 컴퓨팅 리소스
3. 모델 파라미터 설정
4. 에러 로그 확인

**IoT 디바이스 연결 실패**

**해결 단계:**
1. 네트워크 연결 확인
2. 디바이스 설정 재확인
3. 인증 정보 검증
4. 방화벽 설정 확인
