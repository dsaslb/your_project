라이브러리 로드에 실패한 경우, 브라우저 개발자 도구(F12)에서 다음 코드를 실행해보세요:

// Socket.IO 연결 테스트 const socket = io('http://localhost:5000'); socket.on('connect', () => console.log('연결됨:', socket.id)); socket.on('disconnect', () => console.log('연결 해제됨')); socket.on('connect_error', (error) => console.log('연결 오류:', error));
